# JMV Admin

Next.js admin portal for the JMV grocery ecommerce platform.

## Getting Started

```bash
npm install
cp .env.example .env
npm run dev
```

The admin app starts on `http://localhost:3000` by default.

## Scripts

- `npm run dev` - start the development server
- `npm run build` - build for production
- `npm run start` - run the production build
- `npm run typecheck` - run TypeScript checks
- `npm run lint` - run ESLint
